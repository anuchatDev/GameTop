# BRD — One Night Ultimate Werewolf (บอทผู้ดำเนินเกม + ห้องเล่น)

เวอร์ชัน 1.0 · 22 ตุลาคม 2026

## 1. สรุป

เว็บแอปให้เล่น One Night Ultimate Werewolf ได้ทั้งแบบเจอหน้าและออนไลน์ โดยมี **บอทผู้ดำเนินเกมเสียงภาษาไทย**
และ **ระบบสลับการ์ดอัตโนมัติ** ตอนกลางคืน — ไม่ต้องจับการ์ดจริง ไม่มีเสียงขยับตัว ไม่มีใครจำลำดับผิด

## 2. ผู้ใช้

| บทบาท | ทำอะไรได้ |
|---|---|
| Room Host | สร้างห้อง เลือกเซ็ตการ์ด/เวลา กดเริ่มเกม ข้ามเวลาคุย ปิดโหวต เล่นอีกตา — เครื่อง Host เป็นเสียงผู้ดำเนินเกม |
| Player | เข้าห้องด้วย QR / ลิงก์ / รหัส ดูบทบาทตัวเอง ทำแอ็กชันกลางคืน โหวต |
| Spectator | ยังไม่ทำในเวอร์ชันนี้ (BRD ระบุว่า "ถ้ามี") |

## 3. ความต้องการเชิงฟังก์ชัน และสถานะ

### 3.1 ห้องและเซ็ตอัป

| รหัส | ความต้องการ | สถานะ | หมายเหตุ |
|---|---|---|---|
| FR-1.1 | สร้างห้อง + Room Code + QR Code | ✅ | รหัส 4 ตัวอักษร, QR ชี้ไปที่ลิงก์ `?ww=CODE` |
| FR-1.2 | เข้าห้องผ่านลิงก์ / QR / รหัส | ✅ | เปิดลิงก์ก่อนล็อกอินได้ — ล็อกอินเสร็จพาเข้าห้องให้เอง |
| FR-1.3 | เลือกบทบาท — การ์ด = ผู้เล่น + 3 | ✅ | ปุ่ม + / − ต่อบทบาท, ตัวนับสีแดง/เขียว, เริ่มไม่ได้ถ้าไม่ครบ, ต้องมีหมาป่าอย่างน้อย 1 |
| FR-1.4 | ปุ่มแนะนำเซ็ตการ์ด | ✅ | 5 คน = หมาป่า 2, นักพยากรณ์, จอมโจร, ตัวป่วน, ชาวบ้าน 3 (ตาม BRD) — รองรับ 3-10 คน |

### 3.2 เฟสกลางคืน

เซิร์ฟเวอร์ไล่ลำดับเองตามเวลา (ตั้งได้ 10/12/15/20 วินาทีต่อบทบาท) และ **เรียกทุกบทบาทที่อยู่ในเซ็ต แม้การ์ดจะอยู่กลางโต๊ะ** เพื่อไม่ให้ใครเดาได้จากการข้าม

| ลำดับ | บทบาท | ระบบทำอะไร |
|---|---|---|
| 0 | ทุกคน | "ทุกคนหลับตาลง" — ทุกคนเห็นการ์ดตัวเองครู่หนึ่ง แล้วจอดำ |
| 1 | 🐺 หมาป่า | เห็นรายชื่อหมาป่าด้วยกัน / ถ้าตัวเดียว เลือกดูการ์ดกลางได้ 1 ใบ |
| 2 | 🦊 ลูกน้องหมาป่า | เห็นว่าใครเป็นหมาป่า |
| 3 | 🧱 ช่างอิฐ | เห็นช่างอิฐอีกคน |
| 4 | 🔮 นักพยากรณ์ | ดูการ์ดผู้เล่น 1 คน หรือการ์ดกลาง 2 ใบ |
| 5 | 🦹 จอมโจร | สลับการ์ดกับผู้เล่น 1 คน แล้วเห็นการ์ดใหม่ |
| 6 | 😈 ตัวป่วน | สลับการ์ดของผู้เล่นอื่น 2 คน (ไม่เห็นการ์ด) |
| 7 | 🍺 คนขี้เมา | สลับกับการ์ดกลาง 1 ใบ (ไม่เห็นการ์ด) — **ไม่กดภายในเวลา ระบบสุ่มให้** (กติกาบังคับให้สลับ) |
| 8 | 😳 คนนอนไม่หลับ | เห็นการ์ดปัจจุบันของตัวเอง |
| 9 | ทุกคน | "ทุกคนลืมตาตื่นขึ้นมาในตอนเช้า" |

ทุกบทบาทเล่นตาม **การ์ดเริ่มต้น** (การ์ดที่ได้ตอนแจก) ตามกติกาสากล

### 3.3 กลางวันและโหวต

| รหัส | ความต้องการ | สถานะ | หมายเหตุ |
|---|---|---|---|
| FR-3.1 | นับถอยหลังคุย (ตั้งได้) + ดนตรีคลอ | ✅ | 3/5/7/10 นาที · เพลงคลอเบาๆ สังเคราะห์ในเบราว์เซอร์ (เฉพาะเครื่องที่เปิดเสียง) |
| FR-3.2 | Host ข้ามเวลาคุย | ✅ | |
| FR-3.3 | โหวตคน 1 คน หรือคว่ำการ์ดกลาง | ✅ | เปลี่ยนใจได้จนปิดโหวต · ครบทุกคนแล้วปิดเอง หรือหมดเวลา 90 วินาที / Host ปิด |
| FR-3.4 | สรุปผล | ✅ | ใครตาย, การ์ดเริ่มต้น → สุดท้ายของทุกคนและการ์ดกลาง, บันทึกการกระทำตอนกลางคืน, ฝั่งที่ชนะ, ใครชนะ/แพ้ |

**กติกาตัดสิน**

- ผู้ที่ได้โหวตสูงสุด (อย่างน้อย 2 เสียง) ตาย — เสมอกันตายทุกคน · ถ้าโหวต "การ์ดกลาง" ชนะขาด หรือไม่มีใครได้เกิน 1 เสียง = ไม่มีใครตาย
- มีหมาป่าในวง: ชาวบ้านชนะถ้าหมาป่าตายอย่างน้อย 1 ตัว ไม่อย่างนั้นฝั่งหมาป่าชนะ
- ไม่มีหมาป่าในวง: ไม่มีใครตาย = ชาวบ้านชนะ / มีคนตาย = ลูกน้องหมาป่าชนะถ้ายังรอด ไม่อย่างนั้นไม่มีใครชนะ
- ชนะ/แพ้ดูจาก **การ์ดสุดท้าย** ของแต่ละคน

## 4. ข้อกำหนดอื่นๆ

| รหัส | เกณฑ์ | สถานะ |
|---|---|---|
| NFR-1 | Real-time ดีเลย์ ≤ 0.5 วินาที | ⚠️ ใช้การถามสถานะทุก 0.5 วินาที (ไม่ใช่ WebSocket) — วัดบนเครื่อง server ตอบ ~11 ms · ถ้าต้องการต่ำกว่านี้ควรย้ายไป WebSocket |
| NFR-2 | กลางคืนจอมืดสนิท ปุ่มไม่มีเสียง | ✅ พื้นดำ #000, จอสว่างเฉพาะเครื่องที่ถูกเรียก, ไม่มีเสียง/สั่นตอนกด |
| NFR-3 | เสียงบอทภาษาไทยชัด เว้นจังหวะ 10-15 วิ/บทบาท | ✅ ใช้เสียงสังเคราะห์ภาษาไทย (Text-to-Speech) ของเครื่อง, ค่าเริ่มต้น 12 วิ/บทบาท — คุณภาพเสียงขึ้นกับเครื่อง (iOS/Android มีเสียงไทยในตัว, Windows ต้องติดตั้งภาษาไทย) |
| NFR-4 | iOS Safari / Android Chrome | ✅ เว็บ Responsive — iOS ต้องแตะปุ่ม "🔊 เสียงบอท" ก่อนหนึ่งครั้งเพื่ออนุญาตเสียง |

## 5. ยังไม่ได้ทำ / ต่อยอด

- Spectator mode
- WebSocket สำหรับ real-time จริง
- ไฟล์เสียงพากย์จริง (แทนเสียงสังเคราะห์)
- บทบาทเสริม (Tanner, Hunter, Doppelgänger ฯลฯ)
- บันทึกสถิติการเล่นลงโปรไฟล์
