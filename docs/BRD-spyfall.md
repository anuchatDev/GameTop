# BRD — Spyfall

วันที่จัดทำ: 22 ตุลาคม 2026

## 1. สรุป

เกมที่ 5 ของ GameTop — ผู้เล่น 3-12 คนได้การ์ดสถานที่เดียวกันพร้อมบทบาทของตัวเอง ยกเว้นสปาย 1 คนที่ไม่รู้สถานที่
ผลัดกันถาม-ตอบเพื่อจับผิดสปาย ส่วนสปายต้องเนียนให้รอดและทายสถานที่ให้ถูก

## 2. ความต้องการเชิงฟังก์ชัน และสิ่งที่ทำ

| ข้อ | ความต้องการ | สิ่งที่ทำ |
|---|---|---|
| ผู้เล่น / การ์ด | 3-8 คน (ขยายเป็น **3-12 คน** ตามที่ขอ) | 50 สถานที่ (โรงพยาบาล, เรือโจรสลัด, สถานีอวกาศ, คาสิโน, วัด, ตลาดนัด ฯลฯ) แต่ละที่มี 11 บทบาท — 12 คนได้บทบาทไม่ซ้ำกัน · สถานที่ไม่ซ้ำในห้องจนกว่าจะเล่นครบ |
| เวลา | ประมาณ 8 นาที | ค่าเริ่มต้น 8 นาที Host เลือก 5/8/10/12 นาที |
| ถาม-ตอบ | ดีลเลอร์ถามคนแรก, คนตอบได้ถามต่อ, ห้ามตีปิงปอง | Host ถามคนแรก · คนที่ถึงตาแตะชื่อคนที่จะถาม ตาส่งต่อให้คนนั้น · ระบบกันการถามกลับคนที่เพิ่งถาม · ทุกคนเห็นว่าตาใคร · รายชื่อสถานที่ทั้งหมดให้แตะขีดฆ่า (เฉพาะเครื่องตัวเอง) |
| กรณี 1: หมดเวลา | ทุกคนโหวตพร้อมกัน เสียงส่วนใหญ่ถูกคน = คนทั่วไปชนะ | โหวตภายใน 1 นาที (ปิดเมื่อครบ / หมดเวลา / Host กดปิด) · สปายต้องได้คะแนนมากที่สุดคนเดียว — เสมอ = สปายชนะ |
| กรณี 2: กล่าวหา | หยุดเวลา, คนละครั้งต่อรอบ, ต้องเอกฉันท์ | หยุดเวลาเล่น · ทุกคนยกเว้นผู้ถูกกล่าวหาโหวต 👍/👎 (เห็นกันหมด) · เอกฉันท์ → ตัดสินทันที · มีคน 👎 หรือรอเกิน 1 นาที → เล่นต่อจากเวลาที่เหลือเดิม |
| กรณี 3: สปายเผยตัว | หยุดเวลา ทายสถานที่จากรายชื่อ | ปุ่มเห็นเฉพาะสปาย · เลือกจากรายชื่อแล้วยืนยัน · ถูก = สปายชนะ, ผิด = คนทั่วไปชนะ |
| สรุปผล | – | ฝ่ายที่ชนะ, จบด้วยกรณีไหน, สถานที่, ใครคือสปาย, บทบาทและคะแนนโหวตของทุกคน · Host เริ่มรอบใหม่ได้ |

## 3. ความต้องการที่ไม่ใช่ฟังก์ชัน

| ข้อ | สิ่งที่ทำ |
|---|---|
| ความปลอดภัย | สถานที่และตัวสปายอยู่ที่ server — สปายไม่ได้รับชื่อสถานที่จาก API และไม่มีใครเห็นบทบาท/ตัวสปายของคนอื่นจนจบรอบ · สิทธิ์ทุกคำสั่งตรวจฝั่ง server (ถึงตาถาม, เผยตัวได้เฉพาะสปาย, กล่าวหาได้ครั้งเดียว) |
| Real-time | ถามสถานะทุก 1 วินาที (polling) |
| UI | สีประจำเกมเขียวน้ำทะเล · แตะการ์ดเพื่อซ่อน · จอไม่ดับระหว่างเล่น · ตรวจ 6 หน้าจอ × 5 ความกว้าง (320-1920px) ไม่ล้นจอ ปุ่ม ≥ 44px |

## 4. ยังไม่ได้ทำ / ข้อสังเกต

- ถาม-ตอบด้วยเสียงจริง (นั่งเล่นด้วยกันหรือโทรคุย) แอปแค่บอกว่าตาใครและกันตีปิงปอง
- ยังไม่มีระบบคะแนนสะสมหลายรอบแบบ Spyfall ต้นฉบับ และยังไม่ให้ Host เลือก/เพิ่มสถานที่เอง
