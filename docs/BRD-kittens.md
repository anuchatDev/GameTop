# BRD — แมวระเบิด (Exploding Kittens)

วันที่จัดทำ: 28 ตุลาคม 2026

## 1. สรุป

เกมที่ 7 ของ GameTop — ผลัดกันเล่นการ์ดแล้วจั่ว 1 ใบ ใครจั่วเจอ 💣 แมวระเบิดโดยไม่มี 🧯 กู้ระเบิด ตกรอบ
คนสุดท้ายที่รอดชนะ · เกมละประมาณ 15 นาที · 2-10 คน

## 2. ขอบเขต และสิ่งที่ทำ

| ความต้องการ | สิ่งที่ทำ |
|---|---|
| ผู้เล่น / ห้อง | ล็อกอิน (หรือผู้เล่นชั่วคราว) · สร้างห้อง · เข้าด้วยรหัส / ลิงก์ / QR (`?ek=`) · 2-10 คน (6 คนขึ้นไปใช้การ์ด 2 ชุด) |
| เตรียมเกม | ทุกคนได้กู้ระเบิด 1 ใบ + การ์ดอื่น 7 ใบ (8 ใบในมือ) · แมวระเบิด = ผู้เล่น - 1 · กู้ระเบิดที่เหลือใส่กอง (2-3 คนใส่ 2 ใบ ตามกติกา) · สุ่มคนเริ่ม |
| ชุดการ์ด | ชุดพื้นฐาน 56 ใบ: แมวระเบิด, กู้ระเบิด, โจมตี, ข้าม, ขอหน่อย (Favor), สับกอง, มองอนาคต, ไม่! (Nope), แมวธรรมดา 5 แบบ × 4 |
| ในตาของตัวเอง | เล่นการ์ดกี่ใบก็ได้ แล้วจบตาด้วยการจั่ว 1 ใบ |
| โจมตี / ข้าม | โจมตี = จบตาโดยไม่จั่ว คนถัดไปเล่น 2 ตา (โจมตีซ้อน = ตาที่ค้าง + 2) · ข้าม = จบ 1 ตาโดยไม่จั่ว |
| มองอนาคต / สับกอง | ดู 3 ใบบนสุดได้คนเดียว · สับกองแล้วข้อมูลที่ใครแอบดูไว้ถูกล้าง |
| ขอหน่อย / แมว | ขอหน่อย = เพื่อนเลือกการ์ดให้ 1 ใบ (30 วินาที ไม่เลือกระบบสุ่ม) · แมวคู่ = ขโมยสุ่ม 1 ใบ · แมว 3 ใบ = ขอการ์ดตามชื่อ |
| ไม่! (Nope) | เล่นการ์ดแล้วทุกคนมี 4 วินาทีกด "ไม่!" (ไม่ต้องเป็นตาตัวเอง) · "ไม่!" ซ้อน "ไม่!" ได้ นับเวลาใหม่ทุกครั้ง |
| กู้ระเบิด | จั่วเจอแมวระเบิดแล้วมีกู้ระเบิด → ใช้อัตโนมัติ แล้วเลือกใส่แมวกลับเข้ากอง (บนสุด / ใบที่ 2-3 / กลาง / ล่างสุด / สุ่ม) โดยคนอื่นไม่รู้ตำแหน่ง |
| แพ้ / ชนะ | ไม่มีกู้ระเบิด = ตูม! ตกรอบ การ์ดในมือทิ้งหมด · เหลือคนเดียว = ชนะ · Host กดเล่นอีกตาได้ |
| UI | แถบสถานะบอกตาใคร / ตาที่เหลือ / กองจั่ว / แมวระเบิดที่เหลือในกอง · จำนวนการ์ดในมือทุกคน · การ์ดในมือเลือกแล้วระบบบอกว่าเล่นอะไรได้ · บันทึกเหตุการณ์ล่าสุด |

## 3. ความต้องการที่ไม่ใช่ฟังก์ชัน

| ข้อ | สิ่งที่ทำ |
|---|---|
| ความปลอดภัย | กองจั่วและการ์ดในมือเก็บที่ server · แต่ละคนได้แค่การ์ดในมือตัวเอง คนอื่นเห็นแค่จำนวน · ตำแหน่งที่ใส่แมวระเบิดกลับไม่ส่งให้ใคร · ทุกการกระทำตรวจสิทธิ์ที่ server (ตาใคร, มีการ์ดจริงไหม) |
| Real-time | ถามสถานะทุก 0.5 วินาที เพื่อให้กด "ไม่!" ทันในเวลา 4 วินาที |
| ทดสอบ | เทสต์อัตโนมัติ 10 ชุด (แจกการ์ด, ระเบิด, กู้ระเบิด, โจมตีซ้อน, ข้าม, ไม่!ซ้อนไม่!, มองอนาคต, ขอหน่อย, แมวคู่/สามใบ, สิทธิ์ตา) · บอท 4 คนเล่นผ่าน API จนจบเกม · กดในหน้าเว็บจริง (จั่ว / ไม่!) · 4 หน้าจอ × 5 ความกว้าง ไม่ล้นจอ ปุ่ม ≥ 44px |

## 4. ยังไม่ได้ทำ / ข้อสังเกต

- ระบบจับคู่ผู้เล่นอัตโนมัติ (Matchmaking) — ตอนนี้ชวนเพื่อนด้วยรหัส / ลิงก์ / QR
- แมว 5 แบบไม่ซ้ำกัน (เลือกการ์ดจากกองทิ้ง) และส่วนเสริมอื่นๆ
- ไม่มีตัวจับเวลาต่อตา (ถ้าคนถึงตาไม่เล่น เกมจะรอ)
- แอปมือถือแยก — ตอนนี้เล่นผ่านเว็บบนมือถือ
