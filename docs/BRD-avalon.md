# BRD — Avalon (The Resistance: Avalon)

วันที่จัดทำ: 22 ตุลาคม 2026

## 1. สรุป

เกมที่ 6 ของ GameTop — เกมจับคนทรยศ 5-10 คน ฝ่ายดี (อัศวินของอาเธอร์) กับฝ่ายร้าย (สมุนมอร์เดรด)
แข่งกันชนะ 3 ภารกิจจาก 5 แต่ฝ่ายร้ายยังพลิกชนะได้ถ้ามือสังหารหาตัวเมอร์ลินเจอ
กติกาตรงตามบอร์ดเกมต้นฉบับ (ยังไม่มี Lady of the Lake)

## 2. ขอบเขต และสิ่งที่ทำ

| ความต้องการ | สิ่งที่ทำ |
|---|---|
| ผู้เล่น 5-10 คน | ห้อง 5-10 คน · เข้าระหว่างเล่นไม่ได้ · ฝ่ายร้าย 2/2/3/3/3/4 คน ตามจำนวน 5/6/7/8/9/10 |
| แจกบทบาท | เมอร์ลินกับมือสังหารมีทุกเกม · Host เปิด/ปิด เพอร์ซิวาล, มอร์แกนา, มอร์เดรด, โอเบอรอน · ที่เหลือเป็นอัศวินผู้ภักดี / สมุนมอร์เดรด · ระบบไม่ให้เริ่มถ้าตัวละครฝ่ายร้ายเกินจำนวน · ห้องรอแสดงบทบาทที่จะแจกและจำนวนคนในทีมแต่ละภารกิจ |
| ข้อมูลลับของแต่ละบทบาท | เมอร์ลินเห็นฝ่ายร้าย (ยกเว้นมอร์เดรด) · เพอร์ซิวาลเห็นเมอร์ลินกับมอร์แกนาแต่แยกไม่ออก · ฝ่ายร้ายเห็นกันเอง (ยกเว้นโอเบอรอน) · โอเบอรอนไม่เห็นใคร |
| จัดทีม | หัวหน้าเริ่มแบบสุ่ม แล้วเลื่อนตามลำดับที่นั่ง · เลือกได้เฉพาะหัวหน้า และต้องครบจำนวนตามตาราง (2-3-2-3-3 … 3-4-4-5-5) |
| โหวตทีม | ทุกคนโหวตพร้อมกัน เปลี่ยนใจได้จนครบ · เปิดผลเมื่อครบ ทุกคนเห็นว่าใครโหวตอะไร · เห็นชอบเกินครึ่ง = ผ่าน, เสมอ = ไม่ผ่าน · ไม่ผ่านติดกัน 5 ครั้งในภารกิจเดียว = ฝ่ายร้ายชนะทันที |
| ทำภารกิจ | สมาชิกลงบัตรลับ · ฝ่ายดีลงได้แค่ "สำเร็จ" (ตรวจที่ server) · เปิดแค่จำนวนบัตรล้มเหลว · ภารกิจที่ 4 ในเกม 7 คนขึ้นไปต้องล้มเหลว 2 ใบ |
| ตัดสินผล | ล้มเหลวครบ 3 = ฝ่ายร้ายชนะ · สำเร็จครบ 3 = ช่วงลอบสังหาร (มือสังหารเปิดตัว) → ชี้ถูกเมอร์ลิน ฝ่ายร้ายชนะ / ชี้ผิด ฝ่ายดีชนะ |
| บันทึก / สถิติ | กระดานภารกิจ 5 ช่อง · ประวัติการเสนอทีมทุกครั้ง (หัวหน้า, ทีม, ใครโหวตอะไร, ผลภารกิจ) · บันทึกผลทุกเกมลงฐานข้อมูล → อัตราชนะ, จำนวนเกมฝ่ายดี/ร้าย, บทบาทที่ได้บ่อยที่สุด (หน้าสรุปผลและหน้าโปรไฟล์) |
| แจ้งสถานะ | แถบบนสุดบอกตลอดว่ารออะไร เช่น "👑 ต้น กำลังเลือกทีม 3 คน", "🗳️ โหวตทีม — รออีก 2 คน" พร้อมตัวนับทีมไม่ผ่าน x/5 (เตือนตอน 4/5) |

## 3. ความต้องการที่ไม่ใช่ฟังก์ชัน

| ข้อ | สิ่งที่ทำ |
|---|---|
| ความปลอดภัย | บทบาทและบัตรภารกิจอยู่ที่ server · API ส่งให้แต่ละคนเฉพาะสิ่งที่บทบาทนั้นควรรู้ · บทบาทของทุกคนเปิดเผยตอนจบเกมเท่านั้น · ผลโหวตทีมไม่เปิดก่อนทุกคนโหวตครบ |
| เสถียรภาพ | เทสต์อัตโนมัติ 10 ชุด ครอบคลุม 5/7/10 คน, ทีมไม่ผ่าน 5 ครั้ง, ภารกิจล้มเหลว 2 ใบ, ลอบสังหารถูก/ผิด · เล่นจริงผ่าน API ด้วย 7 บัญชีจนจบเกม |
| UI | สีประจำเกมน้ำเงินเข้ม · แตะการ์ดบทบาทเพื่อซ่อน · จอไม่ดับระหว่างเล่น · ตรวจ 6 หน้าจอ × 5 ความกว้าง (320-1920px) ไม่ล้นจอ ปุ่ม ≥ 44px |

## 4. ยังไม่ได้ทำ / ข้อสังเกต

- Lady of the Lake (ส่วนเสริมสำหรับ 7 คนขึ้นไป)
- ไม่มีตัวจับเวลาแต่ละเฟส — Avalon เป็นเกมคุยกันนาน จึงใช้แถบสถานะบอกว่ารอใครแทน
- ใช้ polling ทุก 1 วินาทีแทน WebSocket (เหมือนเกมอื่นในระบบ)
