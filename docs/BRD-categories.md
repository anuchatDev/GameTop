# BRD — ระบบคลังหมวดหมู่และคำศัพท์ (Categories & Word Bank)

## 1. วัตถุประสงค์

ผู้เล่นมักเสียเวลาคิดหมวดหมู่และคำศัพท์หน้างาน — ระบบนี้ให้ผู้เล่น **เลือกหมวด เลือกระดับความยาก แล้วเริ่มเกมได้ทันที**
และสร้างหมวดของตัวเองสำหรับปาร์ตี้พิเศษได้

## 2. ขอบเขต

| ทำ (In-Scope) | ไม่ทำในเวอร์ชันนี้ (Out-of-Scope) |
|---|---|
| หมวดมาตรฐาน 5 หมวด | จับเวลา/นับคะแนนผ่านเสียง (Speech-to-Text) |
| สุ่มคำตามหมวดและระดับความยาก (ง่าย / ปานกลาง / ยาก) | |
| หมวดเฉพาะกิจ (Custom Categories) สำหรับเทศกาล/ปาร์ตี้ | |

## 3. ความต้องการเชิงฟังก์ชัน และสถานะ

| รหัส | ฟีเจอร์ | ความสำคัญ | สถานะ | ใช้งานอย่างไร |
|---|---|---|---|---|
| FR-01 | เลือกหมวดมาตรฐาน 5 หมวด | สูง | ✅ | Host เลือกหมวดในหน้ารอผู้เล่น (เลือกได้หลายหมวด, ไม่เลือก = ทุกหมวด) |
| FR-02 | คัดกรองตามระดับความยาก | ปานกลาง | ✅ | Host เลือก ทุกระดับ / 🟢 ง่าย / 🟡 ปานกลาง / 🔴 ยาก |
| FR-03 | สร้างหมวดเฉพาะกิจ | ต่ำ (Phase 2) | ✅ | หน้า "📚 หมวดของฉัน" — สร้างหมวด ใส่คำ แล้วเลือกใช้ตอนเป็น Host |
| FR-04 | สุ่มคำทีละคำ ซ่อนไม่ให้ผู้ทายเห็น | สูง | ✅ | ในเกม: ระบบแจกคำโดยซ่อนคำของตัวเอง · หน้า "🎲 สุ่มคำ": สุ่มทีละคำ ซ่อนไว้จนกว่าจะแตะดู |

## 4. ความต้องการที่ไม่ใช่ฟังก์ชัน

| ข้อ | เกณฑ์ | สถานะ |
|---|---|---|
| 5.1 Usability | ไอคอนสื่อความหมาย, เริ่มเกมได้ใน 3 คลิก | ✅ ทุกหมวดมีไอคอน — สร้างห้อง → (เลือกหมวด) → เริ่มเกม |
| 5.2 Performance | สุ่มคำ < 1 วินาที | ✅ วัดได้ ~35–130 ms ต่อการสุ่ม 30 คำ (คลัง 1267 คำ) และหน้า "สุ่มคำ" โหลดล่วงหน้าทีละ 30 คำ |
| 5.3 Scalability | เพิ่มหมวด/คำใหม่ได้ง่าย | ✅ หมวดและคำอยู่ในฐานข้อมูล — Admin เพิ่มหมวดมาตรฐานใหม่ได้จากหน้าเว็บ ไม่ต้อง deploy |

## 5. เกณฑ์วัดความสำเร็จ (ยังไม่ได้เก็บข้อมูล)

- **User Engagement** — อัตราการเลือกหมวดซ้ำ
- **Session Length** — เวลาเฉลี่ยในโหมดเกม

> ต้องเพิ่มระบบเก็บสถิติ (analytics) ก่อนจึงจะวัดได้ — ยังไม่อยู่ในเวอร์ชันนี้
