# BRD — Insider (จอมบงการ)

วันที่จัดทำ: 22 ตุลาคม 2026

## 1. สรุป

เกมที่ 4 ของ GameTop — ผู้เล่น 4-20 คนช่วยกันถามคำถามแบบ ใช่ / ไม่ใช่ เพื่อทายคำปริศนาจากคลังคำให้ทันเวลา
แต่ในวงมี **Insider** ที่รู้คำตอบอยู่แล้วแอบชี้นำ เมื่อทายถูกแล้วทุกคนต้องโหวตจับให้ได้ว่าใครคือ Insider

## 2. ความต้องการเชิงฟังก์ชัน และสิ่งที่ทำ

| ข้อ | ความต้องการ | สิ่งที่ทำ |
|---|---|---|
| FR-1 | ห้อง + แจกบทบาท | 4-20 คน · สุ่ม Master 1, Insider 1, ที่เหลือคนธรรมดา · ทุกคนรู้ว่าใครเป็น Master · Host เลือกหมวด/ระดับคำ (ใช้คลังคำร่วมกับเกมคำต้องห้าม รวมหมวดของฉัน) · คำไม่ซ้ำภายในห้อง |
| FR-2 | ดูบทบาท + ถาม-ตอบ | ดูบทบาท 20 วินาที (Host/Master กดข้ามได้) · จับเวลาถาม-ตอบ ค่าเริ่มต้น 5 นาที ปรับได้ 3/5/7/10 นาที · ผู้เล่นพิมพ์คำถาม Master กดตอบ ⭕ ใช่ / ❌ ไม่ใช่ / ➖ ไม่เกี่ยว · บันทึกถาม-ตอบให้ทุกคนเห็น · เล่นต่อหน้าจะพูดถามก็ได้ |
| FR-3 | ทายคำ | พิมพ์ทาย ระบบตรวจให้ (ไม่สนช่องว่าง/ตัวพิมพ์) · Master กด "มีคนทายถูก" แทนได้ · หมดเวลาแล้วยังไม่ถูก → ทุกคนแพ้ · ทายถูก → เวลาที่เหลือ (อย่างน้อย 30 วินาที) ใช้ถกและโหวต |
| FR-4 | โหวตจับ Insider | ทุกคนโหวต 1 คน (ห้ามตัวเอง/Master) เปลี่ยนใจได้ · ปิดเมื่อทุกคนโหวตครบ, หมดเวลา หรือ Host กดปิด · Insider ได้คะแนน**มากที่สุดคนเดียว** → Master+คนธรรมดาชนะ · ผิดคนหรือเสมอ → Insider ชนะ · สรุปผลเปิดเผยคำ บทบาท และคะแนนโหวตทุกคน |

## 3. ความต้องการที่ไม่ใช่ฟังก์ชัน

| ข้อ | สิ่งที่ทำ |
|---|---|
| ความปลอดภัย | คำปริศนาและบทบาทอยู่ที่ server — API ส่งคำให้เฉพาะ Master/Insider และไม่ส่งบทบาทของคนอื่น (ยกเว้น Master) จนจบเกม · ทุกคำสั่งตรวจสิทธิ์ฝั่ง server (เช่น Master เท่านั้นที่ตอบได้) |
| Real-time | ถามสถานะทุก 1 วินาที (polling) — นับถอยหลังบนเครื่องระหว่างรอ |
| UI | สีประจำเกมดำ/แดง/ขาว · แตะการ์ดบทบาทเพื่อซ่อนกันคนข้างๆ แอบดู · จอไม่ดับระหว่างเล่น · ผ่านตรวจ 7 หน้าจอ × 5 ความกว้าง (320-1920px) ไม่ล้นจอ ปุ่ม ≥ 44px |

## 4. ยังไม่ได้ทำ / ข้อสังเกต

- ไม่มีแชทเสียงในแอป — ออกแบบให้นั่งเล่นด้วยกันหรือคุยผ่านแอปโทรอื่น
- ใช้ polling แทน WebSocket (เหมือนเกมอื่นในระบบ)
- ไม่เก็บคะแนนลงโปรไฟล์
